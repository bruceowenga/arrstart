# arrstart

One-command installer for a connected Sonarr • Radarr • Prowlarr • qBittorrent • Jellyfin • Seerr stack. Media management only, no indexers.

arrstart helps anyone go from "nothing installed" to a working, fully connected media automation stack. Paste one terminal command, click through a short web wizard, and finish with Sonarr, Radarr, Prowlarr, qBittorrent, Jellyfin, and Seerr already wired together. Output is a plain `docker-compose.yml` and `.env` you own — no lock-in, no default passwords, no preconfigured indexers or links to content.

## Legal framing

arrstart installs media management software only. It does not bundle, preconfigure, or link to indexers, trackers, or content sources. Users are responsible for what they download and for complying with local law.
