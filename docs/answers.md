# answers.yaml reference

The headless apply engine (`arrstart apply --answers answers.yaml`, WP1.1a)
reads an `answers.yaml` file that describes the stack to deploy. This is the
contract between the user and the apply engine; credentials are never stored
here — they are generated by `internal/credentials` and injected via `.env`.

## Schema (v1)

```yaml
version: 1
preset: movies        # movies | family | custom
apps: []              # required only when preset is custom
media_root: /srv/media     # absolute path (host_os-specific)
host_os: linux        # linux | windows | darwin (default: runtime GOOS)
timezone: UTC         # IANA time zone name (default: UTC)
puid: 1000            # linux/darwin only; rejected on windows
pgid: 1000            # linux/darwin only; rejected on windows
extras:
  vpn: false          # must be false in v1
  tailscale: false    # must be false in v1
```

## Fields

| Field | Required | Default | Notes |
|-------|----------|---------|-------|
| `version` | yes | — | Must be `1` |
| `preset` | yes | — | `movies`, `family`, or `custom` |
| `apps` | custom only | — | App names from the allowed list |
| `media_root` | yes | — | Absolute path for `host_os` |
| `host_os` | no | runtime GOOS | `linux`, `windows`, `darwin` |
| `timezone` | no | `UTC` | IANA time zone name |
| `puid` | no | — | linux/darwin only |
| `pgid` | no | — | linux/darwin only |
| `extras` | no | `{vpn: false, tailscale: false}` | Both must be `false` in v1 |

## Presets

| Preset | Apps |
|--------|------|
| `movies` | radarr, prowlarr, qbittorrent, jellyfin, seerr |
| `family` | sonarr, radarr, prowlarr, qbittorrent, jellyfin, seerr |
| `custom` | whichever apps you list under `apps` |

## Allowed apps

sonarr, radarr, prowlarr, qbittorrent, jellyfin, seerr — the six v1 apps
pinned in `templates/versions.yaml`.

## Validation rules

- `version` must be `1`
- `preset` must be `movies`, `family`, or `custom`
- `apps` is required when `preset` is `custom`
- `media_root` must be an absolute path for the declared `host_os`
  - On Windows: `C:\Media` or `C:/Media` accepted
  - On Linux/Darwin: must start with `/`
- `puid`/`pgid` are rejected when `host_os` is `windows`
- `extras.vpn` and `extras.tailscale` must both be `false` in v1
- No duplicate or unknown app names
- Unknown YAML fields are rejected (strict decoding)

## Example: movies on Linux

```yaml
version: 1
preset: movies
media_root: /srv/media
host_os: linux
timezone: UTC
```

## Example: movies on Windows

```yaml
version: 1
preset: movies
media_root: C:\Media
host_os: windows
timezone: UTC
```
